# Rules Folder Documentation

The `.agents/rules` folder contains categorized rules that guide the behavior and operations of agents in this project. Below is a summary of the rule categories and their descriptions.

## Rule Categories

### 1. **Architecture and Separation**
- **Description**: Rules ensuring clear separation of concerns between frontend and backend components, promoting modular and maintainable architecture.
- **Subfolders**: `backend/`, `frontend/`, `frontend-and-backend/`

### 2. **Frontend UX and Maintainability**
- **Description**: Guidelines for creating user-friendly and maintainable frontend components, focusing on usability and code clarity.
- **Subfolders**: `frontend/`, `frontend-and-backend/`

### 3. **Security and Reliability**
- **Description**: Rules to ensure secure and reliable operations across the system, addressing vulnerabilities and promoting robust error handling.
- **Subfolders**: `backend/`, `frontend/`, `frontend-and-backend/`

### 4. **Testing and Quality**
- **Description**: Standards for testing and maintaining high code quality, including unit tests, integration tests, and quality assurance practices.
- **Subfolders**: `backend/`, `frontend/`, `frontend-and-backend/`

### 5. **Type Safety and Financial Integrity**
- **Description**: Rules emphasizing type safety and financial data integrity, ensuring accurate and reliable financial calculations.
- **Subfolders**: `backend/`, `frontend/`, `frontend-and-backend/`

## Usage
- **Developers**: Refer to these rules to ensure compliance with project standards.
- **Contributors**: Use these guidelines to understand the expectations for agent behavior and implementation.

## Maintenance
- Regularly update the rules as the project evolves.
- Ensure all agents adhere to the latest rules to maintain consistency and quality.
